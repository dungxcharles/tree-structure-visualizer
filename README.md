# Tree Operation

Tree Operation is a JavaFX desktop application for visualizing tree data structures and tree operations step by step. The application supports General Tree, Binary Tree, Binary Search Tree, AVL Tree, and Red-Black Tree.

## Main Features

- Select and visualize multiple tree types.
- Create, insert, delete, update, search, and traverse tree nodes.
- Display algorithm steps during operations.
- Animate tree changes on a JavaFX Canvas.
- Control animation playback, speed, pause/resume, and camera view.
- Support undo/redo operation history.
- Support light/dark theme settings.

## Technology Stack

- Java
- JavaFX
- Maven
- FXML
- CSS

## How to Run

From the project root:

```powershell
cd app
.\mvnw.cmd clean javafx:run
```

On Linux/macOS:

```bash
cd app
./mvnw clean javafx:run
```
